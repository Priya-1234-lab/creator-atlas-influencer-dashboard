# ✦ Creator Atlas – Influencer Browser Dashboard

Creator Atlas is an interactive influencer discovery dashboard that helps users explore creators, compare performance metrics, and understand audience demographics and sentiment insights across Instagram and YouTube.

## 🚀 Live Demo

**Live Website:** https://priya-1234-lab.github.io/creator-atlas-influencer-dashboard/

## ✨ Features

- **Creator Discovery:** Browse 10 creators across Instagram and YouTube.
- **Search:** Search creators by name, username, audience location, or other available details.
- **Platform Filters:** Filter creators by Instagram or YouTube.
- **Sorting:** Sort creators by followers, average views, engagement rate, or name.
- **Engagement Filter:** Filter creators based on engagement rate.
- **Creator Details:** View usernames, user IDs, profile links, followers, post counts, and average views.
- **Audience Analytics:** Explore audience age, location, and gender distributions.
- **Sentiment Analysis:** View positive, neutral, and negative sentiment percentages.
- **Recent Content:** Browse recent posts and videos with thumbnails and engagement metrics.
- **Responsive Design:** Use the dashboard on desktop and mobile devices.

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Priya-1234-lab/creator-atlas-influencer-dashboard.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or installation are required.

## 🌐 Deployment

This project is hosted using GitHub Pages.

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save and wait for deployment to finish.

## 📊 Data Source

The dashboard uses the influencer dataset provided for the assignment. Creator metrics, audience distributions, sentiment percentages, and recent content are displayed from the supplied data.

Metrics are not automatically refreshed from Instagram or YouTube.
